## PROTOKOL UTAMA & ARSITEKTUR KODE
1. **Aturan Chunking "v" (3 Tahap Bertahap)**: 
   - **Bagian 1 (HTML Skeleton & Global CSS)** dikirim setelah prompt ini.
   - Setelah saya membalas **"v"**, lanjutkan ke **Bagian 2 (Main Workspace & UI Components)**.
   - Setelah saya membalas **"v"**, lanjutkan ke **Bagian 3 (JavaScript State Engine & Core Logic)**.
2. **Aturan Non-Destruktif & Placeholder**: 
   - Dilarang keras mengubah, memindahkan, atau menghapus kode, fungsi, dan struktur yang sudah ada kecuali diminta secara eksplisit. Pertahankan kode lama 100% utuh.
   - Untuk efisiensi token, Anda diperbolehkan menggunakan komentar penanda (contoh: `// ... kode sebelumnya tetap utuh ...` atau `/* ... pertahankan bagian ini ... */`) khusus untuk bagian kode yang tidak mengalami perubahan.
3. **Penutup Siklus (Self-Perpetuating Loop)**: 
   - Setelah pengiriman Bagian 3 selesai dan saya membalas **"v"** sebagai konfirmasi akhir, Anda **WAJIB** mengirimkan kembali format prompt ini secara lengkap (dengan *Version History* yang sudah diperbarui) di bagian paling bawah respons Anda.

## ARSITEKTUR MEMORI & STATE (PERSISTENSI)
- **State Management**: Terpusat pada objek global `appState`.
- **Persistensi**: Menggunakan `localStorage` dengan key `SMARTCORE_STATE` (data utama) dan `SMARTCORE_FORM_BACKUP` (input sementara).
- **Sinkronisasi**: Setiap mutasi data (Tambah, Edit, Hapus, Navigasi Tab) wajib memicu fungsi `saveStateToStorage()` dan `renderAll()`.
- **Error Handling**: Wajib menyertakan blok `try-catch` pada operasi `localStorage` untuk mengantisipasi error kuota penuh (`QuotaExceededError`).
